# 30 经济体：历史基础、内部更新与边界

默认游戏无需 API。它采用 **2023 年年度历史统计 + 有界的相关开局扰动**，随后独立模拟，不声称使用今天的市场数据。统计数据包含后续修订，因此也不等同于 2023 年当时已经公开的信息集，不能直接用作无前视偏差的历史回测。

## 覆盖范围

30 种货币，对应 29 个国家和一个欧元区整体；欧元区成员国没有另行建模。

| 区域   | 国家 / 经济体与货币                                                                                              |
| ------ | ---------------------------------------------------------------------------------------------------------------- |
| 北美   | 美国 USD、加拿大 CAD                                                                                             |
| 拉美   | 墨西哥 MXN、巴西 BRL、智利 CLP、哥伦比亚 COP、秘鲁 PEN                                                           |
| 欧洲   | 欧元区 EUR、英国 GBP、瑞士 CHF、土耳其 TRY、波兰 PLN、捷克 CZK、匈牙利 HUF、瑞典 SEK、挪威 NOK、丹麦 DKK         |
| 亚洲   | 中国 CNY、日本 JPY、印度 INR、韩国 KRW、新加坡 SGD、印度尼西亚 IDR、泰国 THB、马来西亚 MYR、菲律宾 PHP、越南 VND |
| 大洋洲 | 澳大利亚 AUD、新西兰 NZD                                                                                         |
| 非洲   | 南非 ZAR                                                                                                         |

30 个统一美元价值可计算 435 组交叉货币对，含反向为 870 个方向。丹麦采用围绕本局欧元交叉起点的 ±2.25% 模型区间；管理浮动货币降低随机冲击敏感度。这些是简化制度，不是完整央行干预、资本管制或汇率篮子模型。

## 数据来源与可追溯性

`packages/simulation/src/data/world-baseline.json` 包含指标值、2023 年份、2026-10-31 提取日期、World Bank 指标链接、精确 Git 镜像提交以及原始 CSV 的 SHA-256。运行 `python scripts/import-world-baseline.py` 可从固定的公开镜像版本重建。导入过程不需要付费 API，不在游戏运行时执行；核心数据缺失会直接失败，不编造原始观察。

| 指标                     | World Bank 指标代码 | 2023 年覆盖 |
| ------------------------ | ------------------- | ----------- |
| 名义 GDP，当前美元       | NY.GDP.MKTP.CD      | 30 / 30     |
| 人口                     | SP.POP.TOTL         | 30 / 30     |
| 年度 CPI 通胀            | FP.CPI.TOTL.ZG      | 30 / 30     |
| 实际 GDP 增长            | NY.GDP.MKTP.KD.ZG   | 30 / 30     |
| 失业率，ILO 模型估计     | SL.UEM.TOTL.ZS      | 30 / 30     |
| 官方汇率，年均本币 / USD | PA.NUS.FCRF         | 30 / 30     |
| 商品和服务出口 / GDP     | NE.EXP.GNFS.ZS      | 30 / 30     |
| 商品和服务进口 / GDP     | NE.IMP.GNFS.ZS      | 30 / 30     |
| 资本形成 / GDP           | NE.GDI.TOTL.ZS      | 30 / 30     |
| 私人部门信贷 / GDP       | FS.AST.PRVT.GD.ZS   | 26 / 30     |
| 中央政府债务 / GDP       | GC.DOD.TOTL.GD.ZS   | 15 / 30     |
| 经常账户余额，美元       | BN.CAB.XOKA.CD      | 30 / 30     |

统一美元价值取官方年均汇率的倒数；经常账户比例由美元余额除以同年名义 GDP 得到。两者在界面标注“统计换算”。年度平均值不是年末现货报价。中央政府债务不等于一般政府债务，外储缓冲指数不等于真实储备金额。

统计缺失保留 null；当前模型为缺失私人信贷使用 80% GDP、缺失中央政府债务使用 60% GDP 的占位情景值，界面明确标记“模型假设”，不能视为对该国的可靠估计。模型政策利率由通胀和风险参数生成融资代理，不冒充官方政策工具。需要精确重现这些国家之前，应补齐相同年份与口径的数据，替换占位假设。

数据经 datasets 公共镜像提供，原始发布者与来源机构包括 World Bank、OECD 和 ILO。保留来源链接和指标定义，适用世界银行数据条款、CC BY 4.0 及上游第三方数据说明；镜像不构成新的统计发布机构。

## 开局扰动

独立的开局随机流组合共同周期、区域周期与本国扰动；不读取玩家账户或持仓。相同种子、版本和参数可复现同一世界。

- 实际增长围绕年度值最多约 ±0.5 个百分点；失业率相反方向最多约 ±0.24 个百分点，存在下界。
- CPI 通胀扰动上限为 `0.35 × max(1, 历史通胀 / 10)` 个百分点，以容纳土耳其等高通胀经济体。
- 浮动汇率对数扰动最多 ±1.5%，管理浮动最多 ±0.45%；丹麦随欧元共同变化，额外相对扰动最多约 ±0.08%。USD 恒定为 1。
- 人口、名义 GDP 与结构比例保持历史基准；政策代理值不随机跳动，预期值可以变化。
- 每个经济体保存原始事实和本局开局值；前端“现实基准与扰动”并列展示原始值、开局值、当前值及来源。
- Twelve Data 可选模式仍仅包含原有 9 种货币，不加开局汇率扰动、不补入其他 21 种历史汇率。默认始终是 30 种货币的离线历史模式。

## 内部经济与更新频率

游戏仍默认 1× 现实速度，可手动加速。每个整游戏小时先读取所有经济体的同一份前置状态，再同时提交更新；不能因为数组排序让某个国家提前获得另一国的新状态。

| 内部状态           | 主要驱动                         | 主要传导               |
| ------------------ | -------------------------------- | ---------------------- |
| 消费增长预期       | 实际工资、就业、实际贷款利率     | 内需、增长与外部收支   |
| 投资增长预期       | 伙伴需求、企业景气、融资成本     | 产出与增长             |
| 工业景气指数       | 增长缺口、外需、供应压力         | 企业投资与事件调查     |
| 工资增长预期       | 通胀预期、劳动力市场             | 实际收入与偿债能力     |
| 信贷与贷款利率     | 政策代理、风险溢价、银行压力     | 消费、住房和投资       |
| 住房增长预期       | 信贷、收入与实际贷款利率         | 家庭和银行风险         |
| 家庭 / 银行压力    | 就业、实际工资、房价与信贷规模   | 融资成本、增长与资金流 |
| 财政余额与债务率   | 支出情景、增长、融资成本         | 需求和风险溢价         |
| 经常账户与外储缓冲 | 历史起点、贸易条件、需求和资金流 | 外部压力观察           |

这些高频值是内部潜在状态和模拟预测，不伪装成每小时发布的官方 GDP、CPI、住房或财政统计。慢变量以时滞推进；央行模型在会议时调整政策代理。各国保留最近 49 个小时观测点和自己的最近 8 条宏观传导记录，避免小经济体记录被大国刷掉。

每个经济体每 24 个游戏小时获得一份内部观察，包括消费、投资、工业景气、融资状态与驱动说明。全球导演每三小时抽样一份调查，轮换通胀、增长、工业与信贷主题；期间可能出现供应、能源、信心和财政事件。事件抽样按相对影响力加权，所有国家的内部经济始终持续更新。

导演仍是读取当前状态与事件记忆的本地提供器，并非外部 LLM。结构和数值边界验证继续生效，央行决议不能由 Agent 提前执行。内部观察当前是确定性分析模板，后续可以换成外部 Agent 叙述层，不改变统计来源或让模型直接写成交价格。

## 当前真实性边界

这是具有现实基础和因果联系的模拟原型，并非已校准的宏观经济预测系统。双边贸易权重根据规模、区域和预设通道生成，行业敏感度与传导系数是模型假设；尚无完整国民账户、财政/银行资产负债表、存量流量一致性、财政政策规则、真实利率制度和资本管制机制。扩充国家不等于已解决这些建模限制。

已有验证覆盖来源与缺失标记、扰动范围与复现、全部币种交叉计算、欧元联系区间、利率到内需的传导、住房到银行的反馈、逐国更新时间和记录，以及 90 天宏观有限性；它们不证明已拟合历史价格分布或交易难度。
