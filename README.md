# FX BATTLER

一个从经济状态、市场预期与事件出发的外汇模拟游戏。所有交易使用虚拟资金。

当前是 **v0.4 可配置的外部 Agent 工作流**：默认 **30 种货币、29 个国家 + 欧元区、435 组唯一交叉货币对（870 个方向）**。内置 2023 年世界银行数据，开局加入受约束的相关扰动，无需 API。各经济体具有逐小时变化的内部经济、每日观察、历史来源对照与趋势图。外部 Agent 调用与后台编排代码已实现；未配置密钥时使用本地导演。模型参数尚未经历史回测校准。

## 本地运行：后端和网页一起启动

安装 Node.js 22+（推荐 24 LTS）和 Git 后：

```bash
git clone https://github.com/panzersaikou/FX_BATTLER.git
cd FX_BATTLER
npm ci
npm run build
npm start
```

保持终端运行，在浏览器打开 **http://127.0.0.1:3001**。没有 API Key 也能玩。稍后把 `.env.example` 复制为 `.env`，配置 Agent 后重启服务即可。上传 GitHub 本身不会启动服务。

Windows、开发模式、Agent 配置及常见问题见 [本地启动说明](docs/run-locally.md)。

## 这版新增

- OpenAI 兼容 Agent 适配器：后端配置 API 基地址、模型和密钥，支持 JSON Schema / JSON Object 两种输出格式。
- 后台生成队列不阻塞交易；结果按发生时状态重新校验。支持取消、超时、有限重试、共享调用额度、冷却与本地降级。
- 世界导演新增模式切换、任务日志、生成与拒绝状态；事件区分 Agent 生成、人工情景和本地降级。无密钥也能正常玩。
- 外部接入步骤、参数与边界见 [Agent 说明](docs/event-director.md) 和 [.env.example](.env.example)。本轮以测试响应验证，没有真实供应商调用。

## 已有玩法与数据

- 5 条与开局经济状态一致的模拟背景，明确标注不是现实新闻，不再重复冲击价格。
- 2024-10-31 至 2026-10-23 的 9,405 条 FRED 日频汇率观测，19 种非美元货币 + USD 基准；支持历史交叉价、周采样图与 CSV 下载，缺失 10 种币种不补造数据。
- 人工事件建议：选择经济体、指标、方向、强度与 1/3/6 小时排程，支持取消、执行记录和校验失败状态。配置外部 Agent 后可结合自由文本提出或拒绝情景；本地导演按结构化选项生成。
- 7 步新手教程与实际开平仓练习；默认下单杠杆 1×，显示名义敞口、保证金与成本说明。
- K 线/收盘折线切换、可开关十字光标（鼠标/触摸/方向键）、视图重置、展开与 Esc 收起。
- 国家特有的模型压力初值与结构锚定，并明确展示共同假设、缺失值占位和相对指数的区别。

数据来源与更新：[汇率历史](docs/fx-history.md)、[经济基准](docs/world-baseline.md)。Agent 接口与人工事件流程：[情景导演](docs/event-director.md)。

## 开发

### 直接体验，不安装依赖

生成的 `artifacts/fx-battler-preview.html` 是独立离线交互版。将它下载到电脑，用 Chrome、Edge 或 Firefox 打开即可；不需要服务器、网络或 API Key。包含 30 种货币的历史基准与内部经济，支持查看 K 线、开平仓、时间推进、经济事件、来源对照和趋势。数据只保存在当前页，刷新会开始新会话。

离线版复用同一套界面、Session、模拟引擎与本地 Agent，只有 API 传输层在文件中改为浏览器内调用。离线 HTML 的外部 Agent 按钮禁用，联网模型需要后端。它不用于多人游戏或真实行情。普通 `npm run dev` / `npm start` 仍使用服务端结算。

需要重新生成离线文件时，在安装依赖后运行：

```bash
npm run build:preview
npm run test:offline
```

### 开发服务器

Node.js 22+，npm 10+。在仓库根目录执行：

```bash
npm ci
npm run dev
```

Vite 开发端口为 5173，`/api` 转发至 3001。API 默认仅绑定 `127.0.0.1`。默认历史基准模式不需要 API Key。

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e
```

浏览器测试优先使用系统 `/usr/bin/chromium`，也支持 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`。没有系统浏览器时先执行 `npx playwright install chromium`。测试会自动启动开发服务器，并生成桌面与移动端截图。

构建后的本地单进程运行方式：

```bash
npm run build
npm start
```

此时 API 会在 3001 端口同时提供构建后的网页。后端通过 `tsx` 运行 TypeScript，属于当前原型的运行方式；生产部署打包、鉴权与持久化尚未实现。构建不等于发布，本项目没有执行任何部署操作。

## 已实现的玩法

- 开局 $10,000 虚拟资金，市场初始暂停；默认 1× 与现实等速（1 秒 = 1 游戏秒），可选择 5× / 15× / 60× / 300× 加速，或手动推进 1 小时后暂停。
- 默认 30 币种历史基准 + 开局扰动，包含中国、印度、韩国、新加坡、巴西、南非等；可查原始统计、单位、年份、开局值与当前模拟值。旧的 Twelve Data 9 币种接口模式继续保留为可选项，不与历史报价混合。
- 切换货币对，查看 5 分钟、15 分钟、1 小时模拟 K 线。K 线周期独立于游戏速度，未收盘蜡烛逐秒形成。
- 每 3 个游戏小时发布一份通胀、增长、工业或信贷调查，期间可能出现供应链、能源、信心或财政事件。经济体按影响权重被选择，较小经济体频率较低。
- 事件从当前经济状态产生，经结构和一致性校验后影响经济变量与预期，再传导到价格；Agent 不能直接写价格、任意状态冲击或提前执行央行决议。
- 逐小时推进进口成本、通胀、增长、就业、政策预期和资金流向，30 个经济体通过贸易网络关联。央行在各自会议日调整实际利率。
- 内部经济包含消费、投资、工业景气、工资、信贷、贷款利率、住房、家庭/银行压力、财政余额、债务、经常账户和外储缓冲；各国逐小时更新并保存最近 49 个观测点，每日生成内部观察。
- 经济体页面可按国家/货币搜索、按区域筛选，查看传导链、贸易伙伴、原始基准与扰动对照。浮动、管理浮动和丹麦的欧元联系制度采用不同的简化模型。
- 1 / 5 / 10 / 20 倍杠杆，市价多空，每笔 100–100,000 基础货币单位，最多 20 个仓位。
- 双边点差、成交滑点、每边名义美元价值的 0.002% 手续费。保证金水平低于 50% 时从亏损最大的仓位开始强平。
- 浮动盈亏按可平仓方向估值；非美元盈亏换算为美元。极端情景允许负余额，不承诺保证金负余额保护。
- 成交记录、经济体观察、事件筛选和详情、新一局、桌面与移动端布局。

## 当前边界

- 2023 年年度统计提供历史基础，数据包含后续修订，不是当前市价或当时可知的信息集。统计缺失、政策利率代理、贸易权重及传导系数明确标记为模型假设；后续数值与 K 线是模拟，不用于真实市场预测。
- 当前为独立仓位模式，反向订单会新建仓位，不自动抵消旧仓位。
- 只有市价单；止盈止损、限价单、隔夜利息、真实交易日历、流动性深度尚未实现。
- 未配置密钥时使用本地导演；外部 Agent 的调用、后台队列与降级已经实现，真实供应商认证和效果需在配置后验证。
- 每个页面会话用不透明 ID 隔离，保存在服务器内存，30 分钟未访问后清除。浏览器刷新可恢复仍存在的会话，重启服务器会丢失。尚不适合公开多人部署。
- 演示模型已实现带时滞的宏观反馈、贸易网络、代表性资金流与政策反应，但参数尚未经历史校准；尚无完整会计体系、订单簿、财政部门、重尾校准或固定汇率制度模型。资本与贸易指标是无量纲压力指数，不是实际资金量或经常账户金额。

## 现实数据与内部模型

数据包含 12 项世界银行指标：10 项覆盖全部 30 个经济体，私人信贷覆盖 26 个，中央政府债务覆盖 15 个。原始指标、精确镜像版本和 SHA-256 保存在数据包中；缺失值保留为空，由模型明确标记假设。详见 [历史数据与内部模型](docs/world-baseline.md)。

## 凭据与平台

服务端读取 `TWELVE_DATA_API_KEY`。本地可以复制 `.env.example` 到仓库根目录 `.env` 并自行填写；已有进程环境变量优先。云环境应在环境设置中安全配置密钥，允许目标域名 `api.twelvedata.com`，不要把密钥发到聊天或放进 `VITE_*` 变量。服务端保留环境代理与 CA 校验，使用 `undici` 的 `EnvHttpProxyAgent`；不跟随上游重定向，不回传原始异常、请求 URL 或上游错误正文。

设置密钥并重启服务后，可以在新局中选择 9 币种 Twelve Data 参考起点；默认仍是无需 API 的 30 币种历史模式。接口失败保留当前游戏，可手动选择历史基准。`GET /api/baseline` 仅返回配置状态，不测试连通性、不消耗额度。普通状态轮询、交易和加速也不消耗行情额度。

每次刷新批量获取 8 个直盘各一根 1 分钟 K 线的 `close`，全服务共享 1 小时内存缓存；无新局就不刷新。批量并不意味着只消耗 1 credit：按每币种 1 credit 估算约 8 credits / 批，最多尝试 24 批 / UTC 日（包含失败），预计本服务最多约 192 credits / 日。实际权限、计费权重和其他程序用量以 Twelve Data 账户为准。缓存和预算目前仅限单进程，重启会清空；多实例部署前需持久化并统一限流。

完整策略、接口和联调步骤见 [参考汇率接入说明](docs/reference-data.md)。离线 HTML 永远使用历史基准，不携带密钥或外部行情请求。

当前推荐网页优先；PWA、桌面封装和小程序的取舍见架构文档。复用现有 checkout，不需要额外 worktree。
